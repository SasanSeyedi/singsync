# SingSync build spec (deadline: today 2026-10-30, submission 16:00 UTC)

SingSync = ComfyUI custom-node pack: song in -> a singing, beat-cut, lip-synced music video out.
Public, MIT. ALL code written fresh in this repo. No secrets, no audio/video, no characters in git.

## Architecture: pure-Python core (`singsync/`) + thin ComfyUI wrappers (`singsync/nodes.py`, root `__init__.py`)
Core must be importable and testable WITHOUT ComfyUI, torch or a GPU. Python 3.10-3.13 compatible. Deps: numpy, scipy (present in ComfyUI). Optional: faster-whisper (import lazily; clear error if missing). ffmpeg via subprocess (path from env SINGSYNC_FFMPEG or PATH).

Data passed between nodes: a custom ComfyUI type `SINGSYNC_PLAN` = a plain dict (JSON-serialisable) + file paths under a work dir (ComfyUI output dir / singsync / run_id).

### Modules (core)
1. `beats.py` - ALREADY HERE (tempo, beats, downbeats, energy, sections, `snap_cuts_to_beats`, `vibe_brief`). Keep API; small fixes allowed; downbeat confidence is weak - do not over-trust it.
2. `align.py` - `transcribe_words(vocal_path, lyrics_text=None, model="small.en", device="auto") -> {"words":[{"word","start","end"}], "lines":[...]}` via faster-whisper with word_timestamps. If lyrics given, align transcript tokens to lyric lines (difflib SequenceMatcher) so each word carries `line_idx`; mark `line_end`. Also `load_alignment(json)`.
3. `cutplan.py` - fresh implementation of the overlap cut planner:
   - Regions: vocal regions = runs of words; gaps > `gap_broll_s` (4.0) become b-roll regions.
   - Vocal cuts: greedily group words up to `target_owned_s` (~8-10 s), prefer breaking at a line end when within `line_snap_frac` (0.6) of target; never exceed `max_audio_s` (Seedance limit; default 12 s for kie Seedance 2, configurable up to 30 for Seedance 2.5).
   - Each cut OWNS [owns_start, owns_end) (contiguous, covering the whole song, no gaps, no overlaps). Its FED audio span extends `overlap_words` (2-3) words into each neighbour: audio_start = start of the word `overlap_words` before the boundary, audio_end likewise after. Record `shared_words_before/after` (words + times) - assembly trims at a shared word.
   - Clip duration bucket: Seedance accepts discrete durations (5/10/15 s for Seedance 2 via kie; 4-30 for 2.5): `duration = smallest allowed >= audio span`.
   - Then call `beats.snap_cuts_to_beats` (boundaries only move inside word gaps).
   - Output dict: song duration, cuts[{idx, owns_start, owns_end, audio_start, audio_end, duration, words, line_text, section, energy, vibe}], config.
4. `slicer.py` - `slice_audio(src, start, end, out)` via ffmpeg (pcm/wav and mp3), per cut; also builds the per-cut prompt: `prompt = f"{style}. {character}. {scene}. The character sings: \"{line_text}\". {vibe}"` with a user template.
5. `retime.py` - lip-sync offset fix (the core novelty). Given the rendered clip and the fed vocal slice: transcribe both (align.transcribe_words), match word sequences (SequenceMatcher on normalised words), anchors = matched (clip_t, slice_t) pairs, offset = median(clip_t - slice_t); if >=4 anchors and spread large, piecewise-linear map. Output `{"offset_s", "anchors", "method"}` and a retimed clip via ffmpeg (`-itsoffset`/trim or setpts with a constant shift; piecewise optional). Pure function `estimate_offset(clip_words, slice_words)` must be unit-tested on synthetic word lists (known shift +-1.7 s, dropouts, extra words).
6. `assemble.py` - for each cut: take its (retimed) clip, trim to its OWNED range mapped into clip time (clip_t = song_t - audio_start + offset), concat in order (ffmpeg concat filter, re-encode h264 yuv420p, constant fps 24), then mux the MASTER song audio (not clip audio) for [0, duration]. Final length must equal song length within 1 frame - test with synthetic colour-slate clips generated by ffmpeg lavfi. Optional `upscale` hook: none here (done with ComfyUI native nodes); optional `fcpxml` export nice-to-have.
7. `captions.py` - karaoke lyric captions: from words -> ASS subtitle file (one line at a time, word highlight via \k tags), burn via ffmpeg `subtitles=` filter; style presets (bold white + outline, bottom third). Unit-test the ASS text.

### ComfyUI nodes (`nodes.py`, NODE_CLASS_MAPPINGS / NODE_DISPLAY_NAME_MAPPINGS, category "SingSync")
- `SingSync Song Analyze` (inputs: song audio path STRING or AUDIO, vocal stem path optional, lyrics STRING multiline, whisper model) -> SINGSYNC_PLAN with alignment + beats.
- `SingSync Cut Plan` (plan, target seconds, overlap words, max clip seconds, allowed durations STRING "5,10,15", snap tolerance) -> plan with cuts; also outputs a STRING cut-sheet table for display.
- `SingSync Cut Slicer` (plan, character STRING, scene/style STRING, prompt template) -> plan with per-cut slice paths + prompts; also a list output usable by a loop.
- `SingSync Seedance (kie.ai)` - SEPARATE FILE `singsync/providers/kie.py` is built by another agent; just leave the node registration import guarded (try/except ImportError).
- `SingSync Retime` (plan) -> plan with offsets per cut + table STRING.
- `SingSync Assemble` (plan, fps, captions BOOLEAN, caption style) -> VIDEO path STRING (+ ComfyUI preview if easy).
Nodes must not block ComfyUI start-up on import errors; heavy imports lazy. No work at import time.

### Also deliver
- `workflows/singsync_music_video.json` - ComfyUI workflow (UI format) chaining the nodes; ok to be minimal.
- `scripts/run_pipeline.py` - CLI that runs the whole chain without ComfyUI (for testing and the demo): `analyze -> plan -> slice -> [render via provider] -> retime -> assemble`, with `--dry-run` that fakes renders with lavfi slates + the fed audio slice delayed by a fake offset (so retime is exercised end to end).
- `tests/` - unittest (no pytest dependency): beats (exists in seedance form - port), cutplan invariants (coverage, contiguity, overlap words, max span, durations), retime offset estimation, assemble length invariant (needs ffmpeg; skip if absent), captions.
- `README.md` - what it is, why it is different (feeds each cut its own vocal slice so the character SINGS; measures and corrects Seedance's early/late singing per clip; cuts on lyric lines + beats; overlap-word trims for sample-accurate assembly), install (git clone into ComfyUI/custom_nodes; pip install faster-whisper optional), node list, the dry-run command, provider notes (kie.ai key via env KIE_API_KEY; Comfy's official Seedance 2.5 reference-to-video node also takes audio clips - swap path), limits, MIT. No hype words.
- `pyproject.toml` (ComfyUI registry style: name singsync, version 0.1.0, license MIT).
